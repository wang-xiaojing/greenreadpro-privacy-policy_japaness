GreenRead Pro
グリーンリード プロ - ゴルフグリーン傾斜測定アプリ

プライバシーポリシー

最終更新日：2026年9月21日

「GreenRead Pro」（以下「本アプリ」といいます）は、ユーザーのプライバシーを尊重し、個人情報の保護に努めています。本プライバシーポリシーは、ユーザーが本アプリを利用する際に取り扱われる情報の種類、その利用方法、および情報の保護方法について説明するものです。本アプリを利用する前に、以下の内容をよくお読みください。

1. 取得する情報と利用目的

1.1 カメラ・LiDAR・センサから取得する情報

本アプリは、ゴルフグリーン上の傾斜・距離・高低差・ブレイクを計測するため、次の情報を端末上で取得・利用します。

  • カメラ映像：端末のカメラ映像（ARKit / RealityKit の AR 空間）を、距離・傾斜の計測および画面上への計測結果の重ね合わせ表示に使用します。
  • LiDAR 深度マップ：LiDAR スキャナが取得する深度情報（Scene Depth）を、グリーン面の3次元形状・高低差・傾斜の推定に使用します。
  • デバイスの姿勢・モーション情報：CoreMotion および ARKit から取得する端末の傾き（X軸・Y軸）やカメラの姿勢を、デバイス姿勢メーターの表示、姿勢ガイド、計測値の補正に使用します。
  • AR トラッキング情報：ARKit が生成するワールド座標・トラッキング状態を、設置したボールとピンの位置関係および計測値の計算に使用します。
端末内で処理されます： これらの映像・深度・センサ情報は、すべて端末内でリアルタイムに処理されるものであり、 写真や動画として端末に保存されることはありません。また、外部のサーバーへ送信されることもありません。

1.2 アプリ内で作成・保存される情報

  • 各種設定値：距離単位、深度平均カーネル、ブレイク中間計算点数、位置決め円の設定、左利きモード、グリーン速度、フォントサイズ、表示レイアウト、ライン色、デバイス姿勢メーターの表示設定など
  • 利用状態に関する情報：初回起動時の同意事項への同意状態、体験期間の累積利用時間
  • 体験期間の初回起動日時：無料体験の開始日時（再インストールによる体験期間のリセットを防ぐ目的で Keychain に保存）
  • 設定バックアップ：ユーザーが任意で書き出す設定データ（JSON ファイル）。書き出し先はユーザー自身が選択します。

1.3 購入に関する情報

  • App Store（StoreKit）を通じた購入状態（全機能版の購入有無）。購入状態は端末内にも保存され、起動時の表示に使用されます。

※購入に関する決済情報（クレジットカード番号等）は Apple が管理し、本アプリは保持しません。

1.4 広告に関する情報

  • 本アプリは、未購入の場合に各画面の上部へバナー広告を表示します。広告の配信には Google が提供する Google Mobile Ads SDK（AdMob）を利用しています。
  • 広告配信事業者（Google）は、広告の配信・不正防止・効果測定のために、端末の種類・OS のバージョン・言語・IP アドレス、広告の表示や操作に関する情報などを取得する場合があります。
  • 本アプリは、他社のアプリや Web サイトをまたいだトラッキングの許可（App Tracking Transparency）をユーザーに要求しておらず、広告目的で広告識別子（IDFA）を利用していません。
  • 広告配信における情報の取り扱いの詳細は、Google のプライバシーポリシーをご確認ください。 https://policies.google.com/privacy?hl=ja

2. 情報の利用目的

本アプリは、取得した情報を次の目的で利用します。

  • カメラ映像・LiDAR 深度情報のリアルタイム処理による、距離・高低差・傾斜・ブレイクの算出
  • ボール・ピン・基準線・狙い線・転がりライン・傾斜方向矢印などの画面表示
  • デバイス姿勢メーターの表示および姿勢ガイドによる計測支援
  • 測定・表示に関する設定値の保存と反映
  • 設定データのバックアップ（書き出し）および復元
  • 購入状態の確認・復元、および無料体験期間の管理
  • 未購入時のバナー広告の配信

※本アプリが取得した計測データを、広告配信やマーケティングを目的として独自に利用することはありません。

3. データの保存場所と保持

  • 計測に用いるカメラ映像・LiDAR 深度情報・センサ情報は、端末内でリアルタイムに処理され、保存されません。
  • 各種設定値および体験期間の累積利用時間は、Apple が提供する仕組み（UserDefaults）を用いて端末内にのみ保存されます。
  • 体験期間の初回起動日時は、端末内の Keychain に保存されます。
  • 設定バックアップは、ユーザーが明示的に操作した場合にのみ、ユーザーが選択した保存先へ JSON ファイルとして書き出されます。
  • 本アプリは、ユーザーの計測データや設定データを外部のサーバーへ送信・保存することはありません（広告の配信を除きます）。
  • 本アプリをアンインストールすると、端末内の設定データ等は削除されます。ただし、体験期間の初回起動日時（Keychain）は、再インストールによる体験期間のリセットを防ぐため残存します。
  • 設定画面の「デフォルト設定に戻す」操作により、設定値をいつでも初期状態に戻すことができます。

4. 第三者提供

本アプリは、法令に基づく場合を除き、ユーザーの情報を第三者へ販売・貸与・提供しません。

ただし、本アプリは次の外部サービスを利用しており、それぞれの提供事業者の定めに従って情報が処理される場合があります。

  • Apple（StoreKit）：購入処理・購入状態の確認・復元は Apple の StoreKit を通じて行われます。
  • Google（Google Mobile Ads SDK / AdMob）：バナー広告の配信は Google の広告配信基盤を通じて行われます。

※本アプリは、これらの事業者に送信される情報の範囲や保持期間を独自に制御することはできません。詳細は各事業者のプライバシー情報をご確認ください。

※端末内で処理される計測データ（カメラ映像・LiDAR 深度情報・センサ情報）を第三者へ提供することはありません。

5. 情報の保護

本アプリは、取り扱う情報の漏えい・滅失・毀損を防止するため、以下の措置を講じています。

  • 計測に関わる映像・深度・センサ情報を端末内でのみ処理し、保存・外部送信を行わない
  • 設定データ等を iOS のアプリサンドボックス内に保存し、他のアプリからのアクセスを制限
  • 体験期間の初回起動日時を Keychain に保存
  • 外部との通信は広告配信に限られ、Apple・Google が提供する仕組みを通じて行われます

6. ユーザーの選択（オプトイン／オプトアウト）

  • カメラへのアクセスは、iOS の権限設定によりいつでも許可／拒否を選択できます。拒否した場合、本アプリの計測機能は利用できません。
  • 測定・表示に関する設定は、アプリ内の設定画面で随時変更できます。
  • 設定データのバックアップ（書き出し・復元）は任意の操作であり、行わなくても計測機能は利用できます。
  • バナー広告は、全機能版を購入することで非表示になります。購入しなくても、計測機能は機能限定の体験版としてご利用いただけます。

7. 子どものプライバシー

本アプリは、13歳未満の未成年者から意図的に個人情報を収集することを目的としていません。未成年者が本アプリを利用する場合、保護者の同意のもとでご利用ください。

  • 本アプリが示す傾斜値・距離・高低差・ブレイクは、LiDAR センサの性能、直射日光・芝の湿り・計測距離・デバイスの姿勢・手ブレなどの影響により誤差が生じる場合があり、あくまで「参考値」です。絶対的な正確性を保証するものではありません。
  • 本アプリは、LiDAR スキャナを搭載した端末（iPhone 12 Pro 以降、iPad Pro）が必要です。
